ABOUT · SCENE 01
IBM CERTIFIED · AI ANALYST

My path into AI/ML didn't start with a bootcamp — it started with curiosity, and a lot of debugging at 6 AM. I taught myself to code from the ground up: Python first, then Java and DSA, then Django, then the data stack.

My first real "it's alive" moment was building Jarvis, a voice assistant on Whisper + Ollama + pyttsx3 — my introduction to actually wiring AI systems together instead of just calling an API.

That curiosity led to NeuroRAG, my first published research, and to KRAG, my current flagship — a multi-tenant RAG SaaS built backend-first, engineered the way production systems actually need to work.
